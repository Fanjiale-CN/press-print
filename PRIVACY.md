# Press-Print Privacy Policy

**Effective date: September 11, 2026**  
**Publisher: Galok / Fan Jiale**  
**Contact: galokview@outlook.com**

## 1. Scope

This Privacy Policy describes the data practices of the Press-Print publisher. It applies to Press-Print's public product pages, documentation, Skill, and Press-Print 2.0 interactive MCP service in compatible host environments such as ChatGPT or Codex.

This policy describes only what the Press-Print publisher does. It does not replace the privacy policy of the host platform a user chooses.

## 2. Publisher and product structure

Press-Print is published by **Fan Jiale**, an individual developer, under the **Galok** brand. Galok is a personal publishing brand and not a separate legal entity.

Press-Print 2.0 consists of:

- a Skill that provides the visual reconstruction and art-direction instructions;
- host-platform image generation or editing capabilities when available; and
- a small Press-Print MCP service used to render optional interactive direction and revision controls.

Press-Print does not operate a separate user account system, payment system, persistent user database, or standalone Press-Print image-generation model.

## 3. What the Press-Print MCP service processes

The Press-Print 2.0 MCP service is designed for data minimization.

Its current tool schemas do **not** accept source-image files or image bytes. The service receives only structured interaction data necessary to render optional UI, such as:

- short source or opportunity summaries generated by the host/model;
- proposed art-direction titles and summaries;
- preservation notes;
- revision-action labels; and
- follow-up instructions associated with a user-selected direction or revision.

Because these fields are generated from the current task, they may contain limited information derived from the user's prompt or source image. Users should therefore avoid including unnecessary sensitive personal information in requests.

The current Press-Print server does not intentionally persist tool-call payloads to an application database and does not intentionally log request bodies for analytics or advertising.

## 4. Information the publisher independently collects

The publisher does **not** intentionally maintain stored copies of:

- source photographs submitted in the host platform;
- generated images;
- complete ChatGPT or Codex conversation histories;
- host-platform account credentials;
- government identification numbers;
- payment information;
- login credentials; or
- advertising profiles.

The publisher may receive or process limited information through the following channels:

| Source | Information | Purpose | Recipient or service involved |
|---|---|---|---|
| Press-Print MCP requests | Structured UI/art-direction fields described in Section 3, plus ordinary network metadata | Render interaction controls and return tool results | Press-Print service and hosting/network infrastructure |
| Public website access | IP address, browser/device type, request time, requested path, and basic technical or security logs | Security, performance, troubleshooting, and network operation | Hosting, CDN, DNS, and security infrastructure providers |
| Email sent voluntarily to the publisher | Sender email address and message contents | Responding to questions, support requests, complaints, or legal notices | The publisher and the email service provider |
| Public GitHub Issue opened voluntarily by a user | Information the user chooses to post | Public project support, bug reports, and feedback | GitHub and the public |

The publisher does not use these channels to build advertising profiles, sell personal data, or conduct cross-site behavioral tracking.

## 5. Host-platform processing

Source photographs, full prompts, conversation content, and generated images are primarily processed by the host platform selected by the user under that platform's own privacy policy, terms, and retention practices.

Press-Print's current MCP tool schema does not request or transmit the source-image file itself to the Press-Print server. Instead, the host/model may send limited structured text derived from the task when the optional interactive UI is used.

Press-Print does not control how a host platform stores, retains, trains on, exports, deletes, or otherwise processes host-platform data. Users should review and use the privacy and account controls offered by the host platform.

## 6. Hosting and network logs

The Press-Print MCP service and public website may rely on third-party hosting, CDN, DNS, and security infrastructure. Those providers may process ordinary technical information such as IP addresses, timestamps, request paths, user-agent information, service logs, and security telemetry as part of operating their services.

Press-Print does not intentionally configure its application code to store tool-call bodies for profiling or advertising. Infrastructure providers may retain operational logs according to their own policies and service settings.

## 7. Cookies and analytics

Unless otherwise disclosed on the relevant public page, Press-Print does not intentionally set advertising-targeting cookies.

The current MCP service does not include an independent advertising or behavioral-analytics system.

If analytics, error monitoring, authentication, or other services are introduced in the future and materially change data practices, this policy will be updated.

## 8. Categories of recipients

Categories of recipients may include:

- the host platform chosen by the user;
- infrastructure providers used to operate the Press-Print MCP service and public website;
- the email service provider used for messages sent to `galokview@outlook.com`; and
- GitHub, when a user voluntarily opens or participates in a public Issue.

Press-Print does not sell personal data, does not sell user content to advertisers, and does not use data brokers.

## 9. Retention

The current Press-Print application does not maintain a persistent user-content database for MCP tool payloads, source photographs, generated images, or conversation histories.

Structured MCP request data is processed to fulfill the request. Ordinary infrastructure logs may be retained according to the schedules and operational practices of the relevant hosting/network providers.

Email sent directly to the publisher may be retained for as long as reasonably necessary to handle the request and maintain ordinary support records. A user may request deletion of information they sent directly by email, subject to reasonable technical and legal limitations.

Public GitHub Issues remain subject to GitHub's controls, policies, and retention practices, as well as actions available to the user who posted the content.

## 10. User images and content

Users should only upload photographs and other materials they have the right to use, including photographs that depict identifiable people.

The publisher does not claim ownership of users' original photographs. The current Press-Print MCP service does not accept source-image files as tool input.

Rights in generated outputs may also be affected by the host platform's terms, applicable law, the rights associated with source material, and third-party rights.

## 11. User controls and requests

Users can stop providing new content to Press-Print by not invoking it or by disconnecting/removing it using controls offered by the host platform.

Deletion, export, training, and similar controls for host-platform chats, uploaded images, and generated outputs are managed through the host platform.

Users should avoid including unnecessary sensitive personal information in prompts or uploaded images because Press-Print's normal reconstruction workflow does not require it.

Do not post private photographs, credentials, or other sensitive information to public GitHub Issues.

To request deletion of information sent directly to the publisher by email, contact `galokview@outlook.com`.

## 12. Children's privacy

Press-Print is not directed specifically to children.

Users must comply with applicable age requirements in their jurisdiction and with the age policies of the host platform they use.

## 13. Sale of personal data and advertising

Press-Print does not sell users' personal data and does not sell user content to advertisers.

Press-Print does not operate an independent advertising system.

## 14. Security

Press-Print uses a data-minimizing architecture intended to avoid unnecessary independent collection of user information. The MCP service accepts a narrow structured schema and does not require a Press-Print account.

No online system can guarantee absolute security. Security measures for host-platform data and third-party infrastructure are also controlled by the relevant service providers.

## 15. International use

Press-Print may be used through host platforms and infrastructure that operate in more than one country.

The current Press-Print MCP service may process structured interaction data through the hosting/network infrastructure used to operate it. The source-image file itself is not part of the current MCP tool input schema.

Privacy requirements vary by jurisdiction. Users are responsible for using the host platform and Press-Print in a manner that complies with applicable law and the host platform's rules.

## 16. Changes to this policy

If Press-Print later adds user accounts, persistent storage, analytics, external image APIs, payments, or other features that materially change its data practices, this Privacy Policy will be updated.

Material changes will be reflected on the public website or project repository with a revised effective date.
