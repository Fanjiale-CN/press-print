# Press-Print Privacy Policy

**Effective date:** 2026-09-09

Press-Print is an image-focused Agent Skill and Skills-only Plugin published by Fan Jiale under the Galok identity. This policy explains the data handling performed by Press-Print itself.

## 1. No independent Press-Print backend

Press-Print does not operate its own user account system, authentication service, MCP server, database, advertising system, or external image-processing backend.

The Press-Print Skill consists of instructions and supporting files used inside a compatible host environment such as ChatGPT or Codex.

## 2. User images, prompts, and outputs

Press-Print itself does not independently transmit user-supplied images, prompts, or generated outputs to Fan Jiale / Galok.

When a user invokes Press-Print in a host product, the host product processes the conversation, uploaded files, model requests, and generated outputs according to that host provider's own terms, privacy policy, account settings, and data controls.

Installing or invoking the Skills-only Press-Print package does not create a separate Press-Print channel that sends conversation or image contents to the publisher.

## 3. Data collected by Press-Print

Press-Print does not intentionally collect or maintain a separate database of:

- names or contact information
- uploaded photographs
- prompts or conversation transcripts
- generated images
- payment information
- precise location
- authentication credentials
- health, financial, or other sensitive personal data

## 4. Public website and repository

Press-Print documentation and policy pages may be hosted on `galok.me` and GitHub. Visiting those services may cause standard web request metadata to be processed by their hosting or infrastructure providers. That website traffic is separate from execution of the Press-Print Skill inside ChatGPT or Codex.

GitHub Issues are public by default. Users should not post private images, credentials, or sensitive personal information in a public issue.

## 5. Third-party host platforms

Press-Print may be distributed through third-party platforms. Their privacy practices are governed by their own policies. Press-Print does not control how a host platform stores, retains, trains on, or otherwise processes content submitted directly to that platform.

## 6. Children

Press-Print does not knowingly operate a separate service directed at children or independently collect children's personal information. Eligibility to use a host platform is governed by that platform's terms.

## 7. Changes to this policy

This policy may be updated when Press-Print's architecture or distribution model changes. A material change, such as adding an external server or independent data collection, should be disclosed before or when that functionality is introduced.
