`Press-Print transforms user-supplied photographs into contemporary print-driven compositions using source-aware reconstruction, selective halftone and duotone treatment, graphic reduction, controlled collage, and modernist hierarchy while preserving the source's semantic identity.`

## Starter prompts

Use these in the Prompts tab. They are intentionally short and adaptable.

1. `Transform this photograph with Press-Print.`
2. `Rebuild this city photo as an editorial print composition.`
3. `Turn this portrait into a Press-Print reconstruction.`
4. `Preserve the main structural anchors and recompose this image.`
5. `Use selective halftone, flat fields, and collage on this photo.`

## Prompt intent

The starter prompts demonstrate the Plugin's core value without requiring internal terminology. They all assume the user attaches a source photograph. Press-Print should directly perform image generation or editing when the host provides that capability rather than returning only a prompt for another model.
